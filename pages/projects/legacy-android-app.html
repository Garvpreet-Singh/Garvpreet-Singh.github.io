Introduction to Android Project

This COMPX202 coursework project focused on building a responsive Android application with four topic areas: About Us, Our People, Outreach, and Research. The app used XML layouts and Java to manage interactions and dynamic data updates.

A key requirement was supporting different screen sizes and orientations while maintaining consistent usability and visual hierarchy.

My Contributions

I designed responsive XML layouts for portrait and landscape, created interactive flows with clickable UI components, and implemented activity transitions for detailed content views.

The project strengthened my Android UI development and version control workflow in Git.
