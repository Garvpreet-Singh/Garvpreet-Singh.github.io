Digital Circuit Design

The Digital Circuit Design project is a software tool designed to simulate the creation and testing of basic digital circuits. Users can build circuits using gates such as AND, OR, and NOT, connect components with wires, and evaluate output behavior in an interactive environment.

A key milestone in this project was refactoring the original implementation with object-oriented design principles, especially inheritance and polymorphism, so new components could be added more cleanly.

My Contributions

I focused on implementing inheritance and polymorphism to simplify and scale the codebase. I also contributed to user interface improvements to make circuit creation and testing more intuitive.

This project helped strengthen my OOP skills and taught me how architecture decisions improve maintainability.
