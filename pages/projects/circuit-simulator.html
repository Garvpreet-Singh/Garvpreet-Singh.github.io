RevoApp Intelligent Monitoring Platform

RevoApp is a full-stack monitoring platform that combines cloud-connected camera feeds, real-time dashboard data, and playback tooling into one operator-focused interface. It was built with React and TypeScript on the frontend and Node.js services on the backend, with support for authenticated cloud API communication and event-driven workflows.

The system enables teams to monitor live camera streams, investigate historical incidents, and retrieve event clips with minimal operational friction. The project involved tackling practical distributed-system problems including token expiry, time alignment between services, and reliable webhook handling.

My Contributions

I developed interactive frontend features for real-time status visibility and implemented secure backend proxy routes for cloud camera services. I also worked on HLS playback and webhook-triggered clip retrieval, with a strong focus on reliability under real-world conditions.

This project strengthened my full-stack engineering skills across API integration, streaming workflows, and production troubleshooting in distributed environments.
