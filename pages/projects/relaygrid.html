RelayGrid (In Progress)

RelayGrid is a decentralised, offline-first disaster communication platform designed for situations where normal communication infrastructure, such as mobile networks or internet access, may be unavailable.

The project explores how nearby devices can communicate using mesh-style peer-to-peer networking, allowing disaster-related information to be shared locally and relayed between users.

Project Aim

The aim of RelayGrid is to investigate and develop a prototype system that supports communication and coordination during disaster scenarios when traditional infrastructure is disrupted.

Key Ideas

  • Offline-first communication
  • Peer-to-peer device discovery
  • Mesh style message relay
  • Local storage of disaster-related information
  • Synchronisation when connectivity becomes available
  • Support for emergency coordination and situational awareness

Technologies Being Explored

  • Bluetooth Low Energy (BLE)
  • Wi-Fi Direct
  • Mobile application development
  • Local data storage
  • Peer-to-peer communication
  • Message forwarding and synchronisation

Status

This project is currently in the early development and planning stage.
