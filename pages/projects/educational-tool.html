How Many Elephants?

How Many Elephants? is an educational web app designed to make abstract numerical values easier to understand through relatable comparisons. Instead of presenting large figures in isolation, the app converts values into practical analogies and contextual explanations that users can quickly interpret.

The platform was created with Python, Flask, and API-driven services to generate dynamic insights for students and general users. It emphasizes clarity, engagement, and critical thinking when working with quantitative information.

My Contributions

I contributed to backend API design and implemented conversion and comparison logic in Flask, ensuring responses were accurate and fast. I also helped integrate Gemini-powered capabilities so users could explore realistic scenarios and better reason about quantities.

This project improved my skills in API integration, educational product design, and communicating technical concepts in a user-friendly way.
